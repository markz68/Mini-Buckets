# Mini Buckets

Mobile-first collection tracker PWA, version 1.0.2.

Features: Store/color dropdowns with + New choices, notes, quantity, lid flag, search/filter/sort, duplicate protection, blank collection for new users; existing local data preserved, offline cache, JSON backup/restore, CSV export.

## Storage
Saved in this browser's localStorage. No automatic cross-device or Google Sheets synchronization. Export JSON backup before resetting browser data or changing phones; import replaces local inventory on confirmation.

## Publish
In GitHub Settings > Pages choose Deploy from branch, main, root. App URL: https://markz68.github.io/Mini-Buckets/

## Test
Open on Android and Windows, add/edit/delete, create new store/color, check duplicate warning, export/import backup, reload offline.
